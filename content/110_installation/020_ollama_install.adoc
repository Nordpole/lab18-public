= Installing Ollama

image::images/image-2025-04-26-14-16-09-425.png[]
Install with one command:

----
curl -fsSL https://ollama.com/install.sh | sh
----

image::images/install_ollama.png[]

image::images/image-2025-04-26-14-27-21-080.png[]

ollama pull llama2
----
